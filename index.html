Виджет онлайн-чата «На связи 24/7»

Демо-страница виджета для сайта «Сибирь Проект» (интеграция с GigaChat API через backend-прокси). Нажмите кнопку чата в правом нижнем углу.

Что реализовано

  • Frontend: чистый HTML/CSS/Vanilla JS, подключение одним скриптом, адаптивная верстка.
  • UX: плавающая кнопка «Онлайн 24/7», приветствие, быстрые подсказки, индикатор «Консультант печатает...», отправка по Enter.
  • Приватность: без полей имени/телефона/email; история чата хранится только в sessionStorage вкладки.
  • Backend: FastAPI-прокси к GigaChat API, безопасное хранение ключа, получение/автообновление access_token.
  • Активные приглашения: через 30 секунд, при прокрутке >50%, при уходе курсора за верхнюю границу и на ключевых страницах. Оператор отправляет приглашение вручную из панели оператора.
  • Живой режим: анонимные ID, heartbeat раз в 15 секунд, список посетителей в панели (обновление раз в 5 секунд), кнопки «Пригласить» и «Подключиться к диалогу». После подключения виджет переключается с ИИ на оператора.
  • Панель оператора: редактируемая библиотека быстрых фраз, вставка по клику и проверка орфографии через Yandex Speller с локальным резервным словарём.

Локальный запуск демо

cd backend
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env  # заполните GIGACHAT_AUTH_KEY
uvicorn main:app --host 0.0.0.0 --port 8000

# Затем откройте index.html через локальный веб-сервер (например):
# python -m http.server 8080  (из корня проекта)
# и откройте http://localhost:8080

В демо виджет обращается к http://localhost:8000/api/chat (см. конфиг ниже).
