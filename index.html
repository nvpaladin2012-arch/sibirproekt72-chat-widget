Виджет ИИ-консультанта «Сибирь Проект»

Виджет подключает базу знаний (разделы сайта, FAQ, цены-ориентиры) и отвечает в анонимном режиме 24/7. Нажмите кнопку чата в правом нижнем углу.

Что умеет виджет

  • Отвечает на вопросы об услугах: банковские гарантии, тендерное сопровождение, КИК, факторинг, ЭЦП, защита в ФАС.
  • Дает ориентиры по ценам и срокам из базы знаний и ссылки на разделы сайта.
  • Работает без сбора персональных данных и направляет в официальные контакты при сложных/индивидуальных вопросах.
  • Использует RAG: поиск релевантных фрагментов базы знаний + генерация ответа моделью (если настроен LLM API). Без API-ключа работает fallback-режим на основе найденных фрагментов.

Как встроить на сайт

<link rel="stylesheet" href="https://ВАШ-ДОМЕН/widget/widget.css">
<script>
  window.SIBIRPROEKT_CHAT_CONFIG = {
    apiUrl: "https://ВАШ-ДОМЕН/api/chat",
    title: "Консультант «Сибирь Проект»",
    subtitle: "На связи 24/7"
  };
</script>
<script src="https://ВАШ-ДОМЕН/widget/widget.js"></script>

Разместите бэкенд (server.py) на сервере, укажите его URL в apiUrl и подключите файлы виджета на страницах сайта.

Быстрый запуск локально

python server.py
# Откройте http://localhost:8000

# (опционально) для генерации ответов LLM:
# Windows PowerShell:
# $env:OPENAI_API_KEY="ваш_ключ"; $env:OPENAI_MODEL="gpt-4o-mini"; python server.py
